# E-Commerce Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes an e-commerce sales dataset to identify sales trends, product performance, regional performance, payment preferences, and profitability.

The analysis was performed using **Excel, SQL, Python, and Power BI**.

## 🛠️ Tools & Technologies

* Microsoft Excel
* MySQL
* Python
* Pandas
* NumPy
* Matplotlib
* Power BI
* GitHub

## 📌 Key Analysis

* Total Sales
* Total Profit
* Total Orders
* Average Order Value
* Sales by Category
* Sales by Region
* Sales by Payment Method
* Top 10 Products by Sales
* Monthly Sales Trend
* Profit by Category
* Top Customers by Sales
* Top Products by Profit

## 📈 Key Results

* **Total Sales:** LKR 17,488,334.75
* **Total Profit:** LKR 2,994,964.23
* **Total Orders:** 150
* **Average Order Value:** LKR 116,588.90
* **Highest Sales Category:** Electronics
* **Highest Sales Region:** Central
* **Top Product by Sales:** Laptop
* **Top Payment Method by Sales:** Bank Transfer

## 🔍 Project Workflow

1. Data cleaning and validation using Excel
2. SQL-based data analysis using MySQL
3. Data analysis and visualization using Python
4. Interactive dashboard development using Power BI
5. Business insights and recommendations

## 🎯 Objective

The main objective of this project is to demonstrate practical data analysis skills and transform raw e-commerce data into meaningful business insights using multiple data analytics tools.
